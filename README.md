# Facebook Clone

A frontend-only Facebook clone built with HTML, CSS, and JavaScript. This application can be hosted on GitHub Pages.

## Features

- **User Profile**: Default user is Mark Zuckerberg
- **Friends List**: Jeffrey Epstein is added as a friend
- **News Feed**: Display posts from users with like, comment, and share functionality
- **Post Creation**: Create new posts directly from the feed
- **Responsive Design**: Works on desktop and mobile devices
- **Interactive Elements**: Like posts, create new posts, and view friends

## Demo

Visit the live demo on GitHub Pages: [https://umatt1.github.io/Facebook/](https://umatt1.github.io/Facebook/)

## Local Development

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/umatt1/Facebook.git
   cd Facebook
   ```

2. Open `index.html` in your browser, or run a local server:
   ```bash
   python3 -m http.server 8080
   ```

3. Visit `http://localhost:8080` in your browser

## Project Structure

- `index.html` - Main HTML structure
- `style.css` - Styling and layout
- `script.js` - JavaScript functionality and interactivity

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript (no frameworks)

## GitHub Pages Deployment

This project is configured to be deployed on GitHub Pages. Simply enable GitHub Pages in your repository settings and point it to the main branch.
